对照陈述与文件

研究问题

来自仓库 README.md 的「前言」与「最近研发群里面看到大家在讨论 脑电图」：FFN 可视化、outlier、规模 / 精度，以及与涌现、顿悟的关系。 涌现部分 README 写的是尚未有好思路。

方法

  • src/model_run.py：forward 收集 all_ffn_out。
  • chat.py：对话循环里用 matplotlib + OpenCV 写 mp4；README 指向约第 48 行的 VideoWriter。
  • chat_interpretability.py：interpretability() 计算标准差、方差、torch.kl_div、99% 分位裁剪。
  • 缺口也来自源码：forward 没有 outlier 参数；仓库没有 options.py。

同一提示、1B5/7B 与 fp16/fp32 对照、输出不可控、7B fp32 未跑，均来自 README「如何得出结论」。 定量五条来自 README「进行可量化的评估试验」，原文标题是「思路」。
